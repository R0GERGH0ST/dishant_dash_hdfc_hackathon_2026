# dishant_dash_hdfc_hackathon_2026

Starter project for HDFC Bank Hackathon 2026.

## Steps to Run the App

From a clean checkout:

```bash
flutter pub get
flutter run
```

The application will launch on the default web target with hot reload enabled.

## Environment Details

- **Flutter SDK:** 3.47.5 (channel stable)
- **Dart SDK:** 3.13.4
- **Platform:** Web (Edge / Chrome / Web Server)
